# Namevya - Discover the Meaning Behind Your Name

Namevya is a modern, clean, and responsive web platform designed to help users discover the meaning, origin, pronunciation, cultural/religious context, and history behind any name.

---

## 🌟 Key Features

- **Modern Hero & Search Bar**: Quick search input with instant interaction and guidance hints.
- **Popular Names Showcase**: Featured popular and trending names with gender tags, cultural origins, and core meanings.
- **Categorized Discovery**: Browse names by category—Cultural & Regional, Historical & Mythology, Nature & Elements, and Modern & Unique.
- **How It Works**: Clear, simple 3-step explanation of the platform's core workflow.
- **Responsive Navigation & Layout**: Mobile-friendly hamburger navigation and flexible grid cards built using standard HTML5 and modern CSS3.
- **Complete Page Suite**: Placeholder pages with consistent header/footer layouts for:
  - About Us (`about.html`)
  - Contact Us (`contact.html`)
  - Privacy Policy (`privacy.html`)
  - Terms of Service (`terms.html`)
  - Disclaimer (`disclaimer.html`)
- **SEO Ready**: Basic meta titles, description tags, and semantic structure across all HTML pages.
- **Zero Dependencies**: Pure HTML, CSS, and vanilla JavaScript—lightweight and blazing fast with no external frameworks or database setup required.

## 🚀 How to Run Locally

Because Namevya is built with lightweight standard web technologies, no build step or installation process is required!

1. **Option 1: Using Python built-in HTTP server**
   ```bash
   python3 -m http.server 8080
   ```
   Open your browser and navigate to `http://localhost:8080`.

2. **Option 2: Open HTML file directly**
   Double-click `index.html` or open it directly in any web browser.
